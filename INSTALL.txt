【群聊世界 V1.9.0】安装说明
作者：ysgl

一、安装插件
1. 将本插件文件夹放入 AstrBot/data/plugins/。
2. 在 AstrBot WebUI 的“插件”页面重载插件。
3. 首次使用请先确认依赖安装完成（requirements.txt 中包含 httpx）。

二、本地 Web 管理
1. 打开插件自己的管理页面。
2. 配置 owner_user_ids / Web 管理口令等原有权限项。
3. Web 管理页面中的“☁️ 云端玩法”是云端唯一配置入口。
4. 标准 AstrBot 配置表单不会再显示 cloud_* 内部配置项。

三、接入 YSGL 云端
1. 打开 https://ysgl.bot.cd/astrbot/ 注册网站账号。
2. 登录 → API Key → 生成 Key，复制完整 gw_live_... Key。
3. 回到 AstrBot → 群聊世界 → ☁️ 云端玩法。
4. 地址默认：https://ysgl.bot.cd/astrbot
5. 粘贴 API Key。
6. 点击“测试连接”或“立即同步”。测试/同步按钮会自动保存当前填写的 Key 和地址。

四、云端 JSON
1. 网站用户上传 Boss / 商品 / 教程 / JSON 后，默认进入待审核。
2. 管理员审核通过后，内容才会进入公开目录。
3. 在 AstrBot 的“☁️ 云端玩法 → 公开 JSON 数据包”中，可以同时勾选多个公开包。
4. 点击“保存选择并同步”。
5. 取消勾选某个包后，再同步即可停止使用。

五、安全
- API Key 只在网站生成时显示完整值；重新生成会立即使旧 Key 失效。
- 插件云端数据使用本地 data 目录缓存，网站暂时不可用时仍使用最近一次成功缓存。
- JSON 不执行任意 Python/JS/SQL 代码。
- 网站管理员与 AstrBot 本地管理员相互独立。
- 网站 data/ 目录应禁止 Web 直接访问。

旧版数据库会在启动时自动添加新增字段和表，不需要手动清库。


V1.9.2 云端：在插件 Page 的“☁️ 云端玩法”中填写 ysgl 网站 API Key，可获取已审核商品、网站公告，并自定义勾选其他用户公开 JSON；保存选择后会把安全识别的数据合并到对应云端目录。
