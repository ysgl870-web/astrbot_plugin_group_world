群聊世界 1.9.0 · YSGL 云端玩法中心配套说明

网站目录：../website/（部署到 https://ysgl.bot.cd/astrbot/）

插件端与网站端保持独立：
- 插件本地数据库与本地配置不依赖网站数据库。
- 网站账号、网站管理员权限与 AstrBot 本地管理员权限不互通。
- 插件只通过 API Key 获取云端公开内容。

云端流程：
1. 网站注册普通账号。
2. 登录后进入“API Key”生成完整 gw_live_... Key。
3. AstrBot → 群聊世界 → ☁️ 云端玩法，填写网站地址和 Key。
4. 点击“测试连接”或“立即同步”。测试按钮会先保存当前输入，避免误测旧 Key。
5. 首次连接成功后自动同步已经审核通过的云端商品、Boss、教程和公开 JSON。

公开 JSON：
- 网站普通用户上传的 JSON 默认状态为 pending。
- 只有网站管理员审核通过后才会进入公开目录。
- AstrBot 云端玩法可同时勾选多个公开 JSON 数据包。
- 只保存 package_no 作为选择清单，取消勾选后下一次同步立即停止使用。
- 预览 JSON 不会自动导入/执行；未知字段只作为数据缓存，不执行任意代码。

云端商品：
- 只有 published 商品会进入 AstrBot 云端商品目录。
- 每个商品拥有独立 item_no 编号。
- 商品效果仅支持安全的数值效果：heal_hp、heal_stamina、add_coins、add_exp。

网站审核：
- 管理后台：/astrbot/admin.php
- 普通用户投稿必须经过管理员审核。
- 驳回需要填写原因。
- 审核、停用用户、撤销 API Key、公告及设置变更会写入审计日志。


V1.13.0：YSGL JSON 可额外发布 payload.bounty_templates 与 payload.global_boss；插件会安全读取为悬赏模板及大世界 Boss Profile，不执行 JSON 中的代码。
