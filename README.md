# AstrBot 群聊世界

作者：**ysgl**
版本：**1.4.0**

把 QQ 群变成一个可长期运行的虚拟世界：玩家、经济、探索、宠物、装备、小游戏、Boss、任务、成就、排行榜、数据审计和 Web 管理中心。

## 1.4.0 更新重点

- 新增独立的“世界超级管理员”权限层，默认高于会话管理员。
- 会话管理员默认只可查看，是否开放具体动作由配置项控制。
- 新增 Web 超级管理员用户名与独立 Web 管理口令。口令使用短时内存令牌，不写入数据库。
- 管理 Pages 重做为 Dashboard 风格控制中心，支持亮暗主题、群组切换、实时刷新、数据导出。
- 新增玩家详细统计：消息量、探索次数、小游戏次数、Boss 总伤害、宠物数、装备数、教程状态、最近活跃等。
- 新增经济流水、世界事件、管理员审计、玩家行为日志。
- 新增 6 页新手教程，注册成功后可自动触发，并支持继续、跳过、重开。
- 新增钓鱼、挖矿、打工、物品使用、装备强化。
- 新增大量高自定义配置，并支持群级 `group_overrides_json`。

## 2. 权限模型

```text
世界超级管理员
    ↓
会话管理员（默认无高危管理权）
    ↓
普通玩家
```

### 世界超级管理员
在插件配置中设置：`owner_user_ids`。也兼容旧版 `admin_user_ids`。

### Web 超级管理员
可以配置：
- `web_admin_usernames`：AstrBot Dashboard 用户名，匹配后可直接进入插件管理中心。
- `web_admin_password`：独立管理口令，页面可以通过口令临时解锁约 6 小时。

### 会话管理员
默认 `session_admin_enabled=false`，只有 `状态` 等低风险操作可以按需开放。使用 `session_admin_allowed_actions` 控制。

## 3. 新手教程

玩家输入 `/注册` 后，在 `tutorial_enabled=true` 且 `tutorial_auto_start=true` 时会自动收到第一页教程。

```text
/教程
/继续教程
/跳过教程
/教程 重开
```

允许在 `tutorial_pages_json` 中覆盖某一页，例如：

```json
{
  "1": "欢迎来到本群世界！先输入 /签到，再输入 /探索。"
}
```

## 5. 数据位置

插件使用 AstrBot 数据目录：

```text
data/plugin_data/astrbot_plugin_group_world/group_world.db
```

导出文件也会临时写入同一插件数据目录。

## 6. AstrBot Pages

当前版本使用官方推荐的插件 Pages + Bridge API 模式：

- 页面位于 `pages/admin/index.html`。
- 后端 API 通过 `context.register_web_api()` 注册。
- 页面通过 `window.AstrBotPluginPage` Bridge 调用后端。
- 页面跟随 AstrBot 亮暗主题。

## 7. QQ 官方机器人

插件通过 AstrBot 的统一事件/消息层工作，并声明支持：

- `qq_official`
- `qq_official_webhook`
- `aiocqhttp`

不会在游戏核心里把业务逻辑硬编码成 QQ 私有协议，因此便于继续扩展其他平台。

## 8. 兼容性

```yaml
astrbot_version: ">=4.16,<5"
```

## 9. 开源与设计说明

本插件使用 SQLite、Python 标准库和 AstrBot 官方插件 API 编写；没有复制外部项目源码。游戏系统为独立设计，并参考常见群聊 RPG / 模拟经营玩法进行组合。


## V1.3.1 重要更新

- 玩家角色改为全局作用域：同一用户跨群共享等级、经验、金币、钻石、背包、宠物、装备、技能和教程状态。
- Web 玩家中心改为全局用户列表，不再按群重复拆分玩家。
- 探索流程改为持久化怪物遭遇，修复连续探索/继续战斗时容易出现的插件调用失败问题。
- 新增普通怪物系统与 7 个内置怪物模板，可在后台通过 `monster_catalog_json` 自定义。
- 新增技能系统：技能清单、学习、装备/卸下、冷却、体力消耗、技能栏。
- 新增技能羁绊：火焰、冰雷、连毒、守护、超载等组合。
- 新增怪物战斗、怪物反击、金币/EXP/材料奖励。
- 商城与背包进一步显示物品作用，支持 `/使用 物品ID 数量`。
- 新手教程扩展为 10 节，覆盖探索、怪物、技能、羁绊、背包、Boss 和长期玩法。
- 世界事件和管理员手动事件会主动广播到对应群；新增定时主动玩法提示。
- 数据库事务增加嵌套事务/保存点兼容，降低连续玩法触发 SQLite transaction 错误的概率。

### V1.5.0 管理与世界增强

- 后台玩家数据中心支持更多成长与统计字段编辑。
- 群组管理增加搜索群聊、世界设置、事件/NPC/Boss 控制。
- 世界事件效果使用统一结算层，商店显示价格与实际购买价格保持一致。
- 怪物支持技能、概率触发、范围伤害和多怪遭遇。
- 群聊可随机出现 NPC，并可选开启 AI 增强 NPC 对话；AI 关闭不会影响正常游戏。
