# 群聊世界 1.13.1

一个面向 AstrBot 的群聊世界插件，提供玩家成长、签到、经济、探索、宠物、装备、小游戏、Boss、任务、成就、排行榜、战斗、决斗、NPC、AI 增强与 Web 管理页。

## ☁️ 云端玩法

配套独立网站：`https://ysgl.bot.cd/astrbot`

AstrBot 本地配置、玩家数据库、Web 管理权限与网站账号相互独立。插件只通过网站 API Key 获取云端公开目录。

### 公开内容来源

- 管理员审核通过的官方内容。
- 当前 Key 账号自己审核通过的内容。
- 其他普通网站用户已经审核通过并公开的内容。
- 已审核通过的社区 JSON 数据包。

### 多 JSON 选择

进入 AstrBot 插件自己的“☁️ 云端玩法”分区，可以直接查看网站已经上架的公开 JSON：

- 支持一次选择多个数据包。
- 选择按 `package_no` 保存，不会把整份 JSON 写进 AstrBot 配置文件。
- 打开“测试连接/立即同步”会自动读取已审核内容。
- 取消选择后，下一次同步会停止使用该包。
- JSON 只是数据，不执行任意代码；未知字段会保留在缓存中。

### 云端商品

云端分区会显示已经审核并公开上架的商品，包括：

- 商品编号。
- 商品名称。
- 介绍。
- 金币价格。
- 作者。

这些商品可与插件商城目录一起使用，本地配置优先，不会无条件覆盖你的本地自定义商品。

## 安装

1. 安装本插件。
2. 网站注册账号并在“设置 → API Key”生成完整 `gw_live_...` Key。
3. 在本插件 Web 管理页 → “☁️ 云端玩法”填入网站地址和 Key。
4. 点击“测试连接”或“立即同步”。

插件网络依赖使用 `httpx`。AstrBot 官方插件开发指南明确建议不要使用 `requests`，网络请求可使用 `aiohttp` / `httpx`。同时持久化数据应放在 `data` 目录，并需要完善错误处理。AstrBot 插件指南也说明了 `metadata.yaml` 是插件识别依赖的元数据入口。见：https://docs.astrbot.app/dev/star/plugin-new.html

## 许可证

本插件继续沿用原插件的许可证与版权说明。


## 云端 Key 连接说明

1. 网站“设置 → API Key”生成完整 `gw_live_` Key。
2. AstrBot “☁️ 云端玩法”粘贴 Key，并打开“启用云端玩法”。
3. 点击“测试连接”。插件同时使用 HTTPS Header 与 POST Body 双通道认证，兼容部分宝塔/Nginx/FastCGI 会丢失自定义 Header 的环境。
4. 云端页面只展示管理员已经审核通过的公开内容；公开 JSON 可以多选，保存后仅同步所选数据包。

## V1.13.0 世界重构与悬赏重做
- 世界系统改为“全局玩家 + 群聊地区”的双层结构：每个群可配置地区、阵营、天气；玩家可跨群旅行，旅行费用与地区危险等级相关。
- 新增世界声望：签到、探索、决斗、悬赏和大世界 Boss 行为可产生声望，并按 100/500/1500/5000/10000 分段生成称号。
- 玩家悬赏改为正式跨群决斗流程：发布时托管奖励金币，目标接受后建立跨群决斗，只有真正击败目标才结算奖励；拒绝、超时或取消可退款，防止凭空刷币。
- 悬赏增加每日发布限制、同时进行中限制、金额上下限、发布费和同目标冷却。
- 大世界 Boss 改为全局共享奖励池，所有参与者按贡献分配；运行时对生命、攻击、防御、狂暴、单次伤害及个人最高奖励再次封顶，极端配置也不会无限膨胀。
- 保留旧数据库并自动迁移，不需要清空玩家数据。

## 📢 独立群发中心

Web 管理页的“系统运维 → 独立群发中心”提供两种模式：

- **立即发送**：手动勾选目标群，自定义消息，按群发送；群聊间隔最低 1 秒。
- **循环发送**：手动勾选目标群，自定义消息与任务名称；群聊间隔最低 1 秒，每轮循环间隔最低 1 分钟。循环任务保存到 SQLite，AstrBot 重启后会继续执行已启用任务。

原有“逐群发送计划”继续保留，不会被新的群发中心覆盖。

## ☁️ YSGL JSON v2

网站发布 JSON 与插件同步内容统一使用 `ysgl_astrbot_group_world` v2：`format + version + metadata + payload`。
`payload` 支持 `products`、`bosses`、`monsters`、`npcs`、`tutorials`、`crafting_recipes`。网站会把旧版直接 payload 自动归一化为 v2，插件仍可读取旧的云端缓存结构。
