# 群聊世界 1.9.2

一个面向 AstrBot 的群聊世界插件，提供玩家成长、签到、经济、探索、宠物、装备、小游戏、Boss、任务、成就、排行榜、战斗、决斗、NPC、AI 增强与 Web 管理页。

## 云端玩法

配套独立网站：ysgl.bot.cd/astrbot

AstrBot 本地配置、玩家数据库、Web 管理权限与网站账号相互独立。插件只通过网站 API Key 获取云端公开目录。

### 公开内容来源

- 管理员审核通过的官方内容。
- 当前 Key 账号自己审核通过的内容。
- 其他普通网站用户已经审核通过并公开的内容。
- 已审核通过的社区 JSON 数据包。

### 多 JSON 选择

进入 AstrBot 插件自己的“云端玩法”分区，可以直接查看网站已经上架的公开 JSON：

- 支持一次选择多个数据包。
- 选择按 package_no 保存，不会把整份 JSON 写进 AstrBot 配置文件。
- 打开“测试连接/立即同步”会自动读取已审核内容。
- 取消选择后，下一次同步会停止使用该包。
- JSON 只是数据，不执行任意代码；未知字段会保留在缓存中。

### 云端商品

云端分区会显示已经审核并公开上架的商品，包括商品编号、名称、介绍、金币价格和作者。

这些商品可与插件商城目录一起使用，本地配置优先，不会无条件覆盖你的本地自定义商品。

## 安装

1. 安装本插件。
2. 网站注册账号并在“设置 → API Key”生成完整 gw_live_ Key。
3. 在本插件 Web 管理页 → “云端玩法”填入网站地址和 Key。
4. 点击“测试连接”或“立即同步”。

插件网络依赖使用 httpx。AstrBot 官方插件开发指南明确建议不要使用 requests，网络请求可使用 aiohttp / httpx。
